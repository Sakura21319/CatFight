# 基米斗-哈基米模拟器

Cocos Creator 3.8.8，TypeScript 横屏猫咪互动游戏。运行时使用横屏 1280×720 设计分辨率。画廊模式保留原有庭院、白笼、方块哈基米和完整互动；第一关“哈基米过马路”单独使用 2D 道路背景、猫精灵和车辆精灵，关卡素材不会覆盖画廊。打开 assets/scenes/Main.scene 后浏览器预览。
GitHub 仓库：https://github.com/Sakura21319/CatFight.git
独立构建：执行 node tests/serve-build.cjs 后访问 http://127.0.0.1:7458 。
编辑器预览：http://localhost:7456/?scene=0a9cbf04-e21a-431e-a58a-156673c2eec5

## 操作

- 点击选择猫咪种类，再轻点地面放置；最多 48 只。
- 拖动地面旋转视角，滚轮缩放；手机可使用向左转、向右转、拉近、拉远按钮，双指捏合也可以缩放。按钮保留较大的触控区域，适配微信小游戏的触屏操作。
- 切换场地：12×10 米大庭院 / 白色笼子，切换时保留猫咪。笼子根据视角隐藏近侧栏杆，保持猫咪可见。
- 全部品种：清空并展示 9 种猫。双猫、三猫演示用于快速检查行为。
- 看猫脸：暂停行为并展示首只猫的近景，再次点击返回。
- 声音：默认关闭，点击开启背景音乐和音效。
- 场上没有猫时背景音乐和所有音效立即停止；声音开关保持开启，下一只猫放入后恢复播放。
- 闯关模式：现有放猫、对峙、缠斗和演示按钮归入画廊模式；闯关入口暂时提供第一关、第二关和第三关预留位。
- 第一关“哈基米过马路”：猫沿斑马线从左向右过马路。车辆垂直上下行驶，车流包含速度更快的普通轿车和较慢的重型卡车；进入马路后猫会自动被最近车辆吸引，玩家只能用横向摇杆或左右方向键/A-D反向抵抗本能。地图全图不规则分布 6 个坑洞，已填坑显示为黄色色块：直接走到右侧即可通关；被撞后先停留 1 秒展示猫饼，再弹出只有提示词“哈基米被自动吸附了”的大字弹窗，点击“继续”才填一个未填坑并从左侧重新开始，点击“返回上一级”则退出本关；最后一个坑在被撞展示后直接弹出只有“世界破破烂烂，基米缝缝补补”的通关弹窗，可返回上一级或进入下一关。另有一次性“起立冲刺”道具，使用后猫自动向右奔跑并撞飞碰到的车辆，到达右侧通关。按 Esc 返回关卡选择时才清空坑洞状态。
- 第二关“老吴的盲区”：银渐层老吴会间歇睁眼，玩家趁闭眼时移动并哈气，哈气值达到 100/100 通关，睁眼时哈气会被发现。

## 模型与行为

躯干是一张闭合的低多边形网格，保留适度棱角；弓背时连续弯曲，无独立分块裂缝。脸部保持 Minecraft 式立体方块造型，并按参考橘猫重做宽扁头型、低折耳、仰视大黑眼、浅色双侧口鼻、粉色短鼻、方块下巴与收紧嘴线，不使用整张照片贴片。原照片只作为美术参考。

9 种外观：橘猫、狸花、三花、彩狸、布偶、英短蓝猫、奶牛猫、暹罗、黑猫。每只猫还会随机获得标准、胖、瘦、长、短五种体型之一，体型通过骨架整体比例体现。橘猫、狸花、三花、彩狸、奶牛猫和黑猫使用独立种子生成的随机花纹；布偶、暹罗保留稳定重点色，英短蓝猫保留稳定纯色质感。随机猫的头部算法会组合虎斑、白鼻线、分脸色块、面罩、口鼻小胡子、额头斑点和冠部花纹，花纹避开眼睛，眼睛和口鼻始终清晰可读。耳朵会随机采用低折耳、直立方耳或宽低耳样式。

单猫会随机走动、跑动、蹲下或趴下；走动速度约 0.46 米/秒，跑动速度约 0.78 米/秒。邻近检测半径 1.9 米。双猫进入对峙后瞬间定位到 1.12–1.40 米的随机距离，身体和腿保持不动；两只猫各自使用独立计时器，每隔 9–18 秒分别从十个侧向角度或朝向对方中随机选择头部方向，因此不会固定同时转头。两只猫的身体方向也分别随机选择，约 78% 概率弓背，也可能保持正常站姿。尾巴按每只猫独立的随机速度和相位分段摆动。单只猫朝向对方的概率为 25%，只有两只猫同时看向对方才会触发缠斗。缠斗随机采用四种动作：侧躺正面抱咬、双方直立面对面对撞抱咬、两只猫侧躺后用四肢互蹬，或两只猫侧躺后腹部相对、前爪抱住彼此、头部错开。互蹬动作会随机错开身体方向。缠斗结束瞬间回到对峙，不播放位移或姿势过渡。“缠斗演示”按钮会依次循环四种动作。三只或更多猫形成邻近连通组时只保持对峙。无尘土或星星粒子。

当场上只有两只猫时，即使相距超过邻近检测范围也会形成对峙配对。远距离触发后只随机选择其中一只猫执行特殊动作，另一只猫随机普通走动或原地不动。“人皇步”触发时一次性随机确定头部方向与两只前爪的方向，之后身体、头和前爪保持不动，只让后腿快速交替向前迈，并以最高约 10 米/秒靠近。“瞬发飞扑”只由动作方执行，在约 0.42 秒内保持腾空姿势，以最高约 13 米/秒高速冲到随机对峙距离。人皇步只比飞扑稍慢。“远距演示”按钮会生成一对相距 6.4 米的猫来直接触发这套逻辑。

每只猫预留 `health` 与 `maxHealth`，当前上限为 100。进入缠斗时双方各扣 28 点；缠斗结束进入 4 秒“嚼口香糖回血”状态，每秒回复 7 点。该状态随机采用站姿或后半身落地、后腿向前伸、上半身与头部抬起的蹲坐姿势，显示沿躯干、头部和腿部轮廓布置的绿色边框，并显示多枚上下悬浮的绿色加号，嘴部持续咀嚼，结束后回到对峙。独立的“老吴撼地掌”恐吓状态不会自动触发，只由按钮触发：两猫距离不超过 2.25 米时，随机选一只猫以 10 米/秒向前位移，前爪下压并向外张开，后腿保持静止，动作约 0.28 秒后结束；距离过远时按钮不触发。界面预留“缠斗演示”“老吴撼地掌”和“口香糖演示”按钮，便于直接检查状态。数值与状态衔接均可在后续完整状态机中替换。

游戏图标来自 `assets/branding/game-icon.png`，Web 构建模板使用同一图片作为 favicon 和 Apple Touch Icon。

## 替换音频

占位音频为本地程序合成，无第三方音乐素材。替换以下文件、保持文件名，然后重新构建即可：

- assets/resources/audio/music.wav：16 秒循环背景音乐。
- assets/resources/audio/laowu1.mp3 至 laowu5.mp3：每次进入对峙随机播放一条，并尽量避免连续重复。laowu6–8 即使后续保留在 audio 文件夹中，也不参与当前随机播放。
- assets/resources/audio/fight.wav：缠斗声占位。
- assets/resources/audio/place.wav：放置提示音。

GardenAudio.ts 控制加载和音量。可用 node tests/generate-audio.cjs 重新生成占位文件（会覆盖上述 WAV）。当前不是实录猫叫。

## 检查

node tests/rules.test.cjs
node tests/voxel-pose.test.cjs
node tests/surface.test.cjs
node tests/breeds-space.test.cjs

类型检查要在项目终端里执行 Cocos 安装包自带的 TypeScript，不要在资源管理器里双击 `tsc` 或 `tsconfig.json`；后者会触发 Windows 的“选择打开方式”提示。PowerShell 命令为：`& 'C:\ProgramData\cocos\editors\Creator\3.8.8\resources\app.asar.unpacked\node_modules\typescript\bin\tsc' --noEmit --skipLibCheck -p tsconfig.json`。skipLibCheck 跳过 Cocos 引擎内部声明缺失，仍检查项目脚本。

源码按 CatGarden（交互与调度）、VoxelCat（模型与动作）、CatSurface（连续网格）、CatBreeds（品种花纹）、GardenSpace（距离）、CatEnvironment（场地）、GardenAudio（音频）划分。

已生成 build/web-mobile。构建目录由 Cocos 管理，不在那里改源码。微信 AppID、真机性能和 48 只猫上限的低端设备性能尚未验证；正式移动版本仍需合批和模型优化。
