# 第二关：城市车流

第二关正式替换旧的“老吴的盲区”。玩法为横屏四车道长街：猫自动向右前进，玩家通过右侧上下力度条抵抗猫自动钻向车辆底部的本能。

## 文件职责

- `assets/scripts/level2/TrafficTypes.ts`
  - 车辆种类、道路事件、四车道坐标、关卡长度和车辆吸附参数。
  - 不包含 Cocos 节点和 UI。
- `assets/scripts/level2/TrafficGenerator.ts`
  - 生成隐藏安全走廊。
  - 在安全走廊之外生成高密度车流。
  - 在生成阶段做时空重叠检查。
  - 施工和事故路段参与开放车道约束。
- `assets/scripts/level2/Level2Traffic.ts`
  - Cocos 运行时控制器。
  - 复用 `road-cat`、`road-cars` Asset Bundle。
  - 管理上下力度条、自动前进、多车吸附合力、碰撞、跟车、急刹、变道、堵车、雨天湿滑、施工并道和事故封路。
  - 运行时绑定现有“第二关”卡片，不修改第一关玩法逻辑。
- `assets/scripts/level2/Level2MenuPresenter.ts`
  - 只负责把原“敬请期待”文案替换成正式第二关说明。

## 当前关卡节奏

1. 安全起步区：完全不生成车辆。
2. 畅通车流。
3. 施工并道：封闭 1 条车道，部分车辆提前并线。
4. 堵车：车距缩短、走走停停、急刹和加塞概率提高。
5. 雨天湿滑：前方可视区域变暗，玩家控制力下降、惯性增强。
6. 短暂畅通。
7. 事故：中间 2 条车道关闭，四车道临时压成两条通路。
8. 事故后拥堵。
9. 终点前恢复畅通。

## 生成原则

车辆不是直接随机撒在道路上。算法先生成一条隐藏的连续安全走廊，然后只尝试在走廊之外生成车辆；候选车辆还会预测其经过玩家附近时的位置，如果与已有车辆发生时空重叠则拒绝生成。

运行阶段同车道车辆还有跟车逻辑，因此不会因为速度差持续追进前车内部。

## 吸附

第二关使用多车辆合力，不再只选择最近一辆车。每辆车根据距离贡献一个上下方向吸附力，越靠近增长越快。

危险度从低到高：普通车 < 公交 < 大运。大运目前复用现有 `truck-sprites`，后续如需更明显的大运视觉，可替换素材而无需改玩法逻辑。

## 维护边界

新增道路事件优先通过 `TrafficTypes` + `TrafficGenerator` 配置和约束完成，不要把事件判断继续堆进 `CatGarden.ts`。

第一关现有道路逻辑暂不大范围重写，以降低回归风险。后续如要继续整理，可单独把第一关抽成 `level1` 模块，再逐步瘦身 `CatGarden.ts`。
